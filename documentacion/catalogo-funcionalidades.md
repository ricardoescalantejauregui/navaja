# Navaja — Catálogo de funcionalidades

Nov 2, 2026 · @Ricardo Escalante Jauregui

Catálogo propuesto de Navaja: 68 herramientas gratuitas en la v1 (38 para desarrollo y 30 para diseño) y funcionalidades de pago en la v2. Falta marcar cuáles existen ya en el sitio actual.

## v1 gratuita: desarrolladores (38)

- **Formateadores:** JSON (formatear, minificar, validar, ver en árbol), SQL, XML.
- **Convertidores:** JSON ↔ YAML, JSON ↔ CSV, bases numéricas, fecha y Unix timestamp, expresiones cron, unidades CSS (px, rem, em, %, vw), cURL a código (fetch, Python requests, C# HttpClient).
- **Codificadores:** Base64 de texto, Base64 de imagen o archivo, URL encode/decode, entidades HTML, decodificador JWT, GZip/Deflate, generador QR, lector QR.
- **Generadores:** hash y checksum (MD5, SHA-1, SHA-256, SHA-512), HMAC, UUID/ULID/NanoID, contraseñas, lorem ipsum, datos falsos (con RFC y CURP ficticios), JSON a tipos (TypeScript, C#, Pydantic), tablas Markdown.
- **Texto:** probador de regex, comparador de texto (diff), comparar listas, escapar cadenas, utilidades de texto (contar, ordenar, cambiar caso), slug, vista previa Markdown, JSONPath, analizador de User-Agent.
- **Validadores:** JSON Schema.
- **Red y referencia:** calculadora de subredes, códigos HTTP.

## v1 gratuita: UX/UI y diseño gráfico (30)

- **Color:** convertidor (HEX, RGB, HSL, OKLCH, CMYK), verificador de contraste WCAG/APCA, generador de paletas, escala de tonos 50–950, paleta desde imagen, cuentagotas de pantalla, simulador de daltonismo, degradados, mezclador de colores.
- **Tipografía y layout:** escala tipográfica, `clamp()` fluido, probador de fuentes locales, generador de grid CSS, playground de Flexbox, calculadora de relación de aspecto, escala de espaciado 4/8 pt.
- **Efectos CSS:** sombras, border-radius y formas, glassmorphism, curvas cubic-bezier, patrones SVG.
- **Imágenes y assets:** convertidor (PNG, JPG, WebP, AVIF), compresor, redimensionar y recortar, optimizador SVG, SVG a componente (JSX, Vue, Data URI), generador de favicons, imágenes placeholder, vista previa Open Graph, tokens de diseño a CSS/SCSS/JS.

## Comunes a todas las herramientas

Pegar, cargar ejemplo, limpiar, copiar, descargar, arrastrar archivo, resultado en vivo, errores en línea, favoritos, recientes, atajos de teclado, tema claro/oscuro y funcionamiento offline.

## v2 de pago

- **Todos los perfiles:** nube con historial y snippets, enlaces cifrados para compartir, procesamiento por lotes.
- **Desarrolladores:** API REST, CLI, asistente IA (regex, SQL, explicar código), mock API, inspector de webhooks, cliente HTTP con colecciones.
- **UX/UI:** auditoría de accesibilidad de una URL, capturas y generación de imágenes Open Graph, exportar tokens a Figma, Tailwind, iOS y Android, plugin de Figma.
- **Diseño gráfico:** quitar fondo con IA, vectorizar y escalar con IA, maquetas con dispositivos, exportación CMYK para impresión.
- **Equipos:** kit de marca compartido, roles, facturación centralizada.
